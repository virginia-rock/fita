# Contribuindo com o Fita.

Obrigado pelo interesse em melhorar o Fita. Contribuições são bem-vindas por
meio de issues e pull requests.

## Como contribuir

1. Faça um fork do repositório.
2. Crie uma branch descritiva a partir da branch principal:

   ```bash
   git checkout -b minha-melhoria
   ```

3. Faça uma mudança pequena e focada.
4. Rode as verificações disponíveis antes de abrir o pull request:

   ```bash
   npm run build
   npm run lint
   ```

5. Faça commit das alterações e abra um pull request explicando o que mudou,
   por que mudou e como foi testado.

## Diretrizes

- Preserve o foco do projeto: registro e acompanhamento corporal com clareza,
  privacidade e armazenamento local.
- Não inclua chaves, tokens, dados pessoais ou arquivos gerados no commit.
- Prefira mudanças acessíveis, responsivas e compatíveis com o visual existente.
- Atualize a documentação quando o comportamento ou o fluxo de uso mudar.
- Issues para bugs devem incluir passos para reproduzir o problema e o
  comportamento esperado.

Todo pull request passa por revisão e pode receber sugestões ou ser recusado
se estiver fora do escopo do projeto.
